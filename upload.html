📸 फ़ोटो लाइब्रेरी अपलोडर

⚙️ सेटिंग (सिर्फ़ पहली बार)

Token बनाने का तरीका: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access में सिर्फ़ बॉट वाली repository चुनें, और Permissions में Contents: Read and write दें। यह token सिर्फ़ आपके इसी फ़ोन के ब्राउज़र में रहता है, कहीं और नहीं जाता।

हर नाम का अलग फ़ोल्डर बनेगा। नाम वही लिखो जो आम तौर पर अंग्रेज़ी में लिखा जाता है, जैसे rohit sharma, india team, india vs pakistan। किसी भी टॉपिक की आम फ़ोटो (स्टेडियम, भीड़, मैदान) के लिए नाम में general लिखो।
